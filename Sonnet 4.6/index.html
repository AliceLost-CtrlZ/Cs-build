Fractal Geometry
The Mandelbrot Set
The set of complex numbers c for which z → z² + c remains bounded. A simple rule producing infinite complexity at every scale. Click anywhere to zoom in — the boundary is infinitely detailed.

Parametric Curves
Lissajous Figures
Named after Jules-Antoine Lissajous, these figures arise from two perpendicular harmonic motions: x = sin(at + δ), y = sin(bt). The phase δ slowly rotates, morphing the curve continuously. When a/b is rational, the curve closes.

Harmonic Analysis
Fourier Epicycles
Any periodic signal decomposes into a sum of sine waves. Rotating circles (epicycles) at odd harmonics approximate a square wave — each circle's radius is 4/(π·n). The overshoot at discontinuities (~9%) never vanishes: the Gibbs phenomenon.

3
Each new harmonic (1, 3, 5, 7 …) sharpens the edges. Drag Harmonics from 1 to 40 and watch the square wave emerge. The persistent ringing at corners is the Gibbs phenomenon — a fundamental property of Fourier series.
Number Theory
The Ulam Spiral
In 1963, Stanisław Ulam doodled integers in a spiral during a lecture and noticed primes cluster on diagonal lines — a pattern still not fully explained. Colors show the angular position in the spiral, revealing diagonal structure.
101
The diagonals hint that quadratic polynomials like Euler's n² + n + 41 generate primes at exceptional rates. Increase the grid size to see the diagonals sharpen across hundreds of numbers.
